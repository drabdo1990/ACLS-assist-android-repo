# SHA Pediatric Advanced Life Support Provider Course

The pediatric content in this app summarizes the learning objectives of the
Saudi Heart Association (SHA) PALS Provider Course.

The full SHA PALS provider course text is copyrighted material of the Saudi
Heart Association and is not distributed with this repository.

- Official PALS Provider Manual: https://saudi-heart.com/pals-provider-manual/
- Saudi Heart Association (KSA CPR) course portal: https://saudi-heart.org/
